A modern, responsive, and interactive 3D portfolio website built for showcasing Artificial Intelligence, Machine Learning, and Data Science projects. Featuring a custom Three.js Neural Matrix visualization, glassmorphism UI, light/dark themes, and real-time background customization.

## ✨ Features

- **Interactive 3D Neural Canvas:** Custom WebGL scene built with Three.js featuring an icosahedron core, orbital rings, particle cloud, and responsive cursor parallax.
- **Dynamic Theme Switcher:** Seamless Dark and Light mode toggle with `localStorage` persistence.
- **Workspace Background Customizer:** Modal tool allowing instant switching between:
  - 3D Neural Lattice (Three.js WebGL)
  - Deep Space Radial Glow
  - Cyber Matrix Grid
  - Custom Remote Image URLs or Local File Uploads
- **One-Click Resume Download:** Direct download trigger for offline CV access.
- **Glassmorphism UI:** Fully tailored Tailwind CSS glass components with dynamic blur and borders.
- **Mobile First & Fully Responsive:** Optimized layout across mobile, tablet, and widescreen displays.

---

## 🛠️ Tech Stack

* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (via CDN)
* **3D Graphics:** [Three.js](https://threejs.org/) (r128)
* **Icons:** [Lucide Icons](https://lucide.dev/)
* **Typography:** Plus Jakarta Sans & JetBrains Mono (Google Fonts)
